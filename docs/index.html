HermitCrab Writing

A Markdown writing app for the Mac.

Your library is a folder of plain .md files. Open them in any other editor, back them up however you like, and keep them if you ever stop using this app.

Download for Mac For Macs with Apple silicon. Once installed, it keeps itself up to date. Older versions

What it does:

  • Collections and projects keep different kinds of writing apart. Each project has notes and canvases for planning beside the work itself.
  • Focus mode hides the sidebars and dims everything but the paragraph you're on. Typewriter mode keeps your line in the middle of the screen.
  • Grammar checking that runs on your Mac, not on someone's server.
  • Screenplays in Fountain.
  • Export to Markdown, HTML or PDF.
  • Sync through iCloud Drive or a GitHub repository.
