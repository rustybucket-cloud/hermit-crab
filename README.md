# Hermit Crab

Hermit Crab is a quiet, Markdown-based writing app for the Mac, iPhone and iPad, in the spirit of Ulysses. You organise your writing into collections and projects, write in a distraction-free editor with focus and typewriter modes, plan with notes and visual canvases, write screenplays in Fountain, and export to Markdown, HTML or PDF. Your library is just a folder of plain `.md` files on disk, and it can sync through iCloud Drive or a GitHub repository.

## Usage

1. Download the latest `.dmg` from [Releases](https://github.com/rustybucket-cloud/hermit-crab/releases), open it, and drag Hermit Crab into Applications. The app keeps itself up to date.
2. Open the app and start writing. Your library lives in `~/Documents/Hermit Crab`; change it from **File → Change Library Location…**.
3. To sync, open **Settings → Sync** and connect a GitHub repository, or put your library in an iCloud Drive folder.

To run from source instead, use [pnpm](https://pnpm.io/installation):

```sh
pnpm install
pnpm dev
```
